# 이미지 분석 평가 자료

이 자료는 합성 이미지다. 외부 계정이나 실제 고객 문서가 들어 있지 않다.
`fixtures/`의 PNG 다섯 개가 기준 자료이며 생성 스크립트와 설명은 CC0-1.0이다.

같은 자료를 다시 만들려면 Pillow와 한글을 지원하는 글꼴이 필요하다. 글꼴에
따라 픽셀·파일 해시가 달라지므로 아래는 **새 폴더**에 생성한다.

```sh
python benchmarks/image-eval/generate.py --output /tmp/tokensaver-docs-image-eval --font /path/to/korean-font.ttf
```

## 사람이 확인할 기준

| 파일 | 최소한 확인할 사실 |
| --- | --- |
| text.png | 환불 안내, 배송 후 7일, 주문 제작 제외, 12,500원. 숫자·조건이 바뀌지 않아야 한다. |
| no-text.png | 글자가 없다는 표시와 산·해·태양이 보이는 그림이라는 설명. 실제 사진이 아닌 합성 그림이다. |
| chart.png | 월별 주문 수, 1월 10·2월 20·3월 15와 2월이 가장 높다는 관계. 축에서 추가 단위를 지어내지 않는다. |
| flow.png | 신청 → 검토 → 완료의 순서와 오른쪽 방향 화살표. 역순이나 존재하지 않는 조건을 만들지 않는다. |
| occluded.png | 주문번호가 가려져 판독 불가함을 밝히고, 상태는 확인 필요라고 기록한다. 가려진 번호를 추측하지 않는다. |

각 단독 PNG와 다섯 이미지를 순서대로 포함한 HTML로 각각 처리한다. 이미지와
글자·설명의 위치, 원본 이미지 일치, 선택하지 않았을 때 모델 호출 0회,
중복 이미지 한 번 처리, 재실행 시 추가 호출 0회, 실패 후 이어하기 및 기존
MD 보존도 확인한다. 적어도 각 모델·파일의 결과를 열어 위 사실, 틀린 설명,
불필요한 추측, 판독 불가 표시를 기록한다. 자동 문자열 검사는 의미 정확도를
보장하지 않는다.

예제 HTML은 `fixtures/examples.html`이며 첫 번째 이미지를 마지막에 다시
넣어 중복 재사용도 확인한다. 실제 모델 비교 전에 저장 폴더와 캐시 조건을
기록하고, 한 번 실행한 결과와 그대로 다시 실행한 결과를 구분한다. 공통
이미지 처리 결과가 단독 PNG와 HTML 사이에서도 재사용되는지 확인한다.

## 측정 기록

매 실험에 입력 파일 해시, 도구·모델 버전, 실행일, 이미지 픽셀 크기, 확대
조각 수, 첫 실행/재사용/실패 재시도별 모델 요청 수, 시간, 결과 상태,
사람이 확인한 누락·오답을 기록한다. 제공자가 반환한 실제 입력·출력 토큰은
`actual_input_tokens`와 `actual_output_tokens`로 기록하고 없으면 null로 둔다.
텍스트 토크나이저 추정치는 `estimated_text_tokens`와 인코딩 이름으로 따로
기록한다. 추정치에는 이미지 토큰과 호스트 지시문·도구 스키마가 포함되지
않을 수 있다. 호출 횟수 1회만으로 비용이나 토큰 절감을 주장하지 않는다.

이 자료만으로 실제 업무 문서의 정확도나 토큰 절감률을 일반화하지 않는다.
모델 호출은 이 안내가 실행하지 않는다. 실제 모델 평가는 사용자가 선택한
제공자와 모델의 가용성·가격을 확인하고 진행한다.
